# Circuit
可以通过代理和edge浏览器访问https://wolf-reef-wind-urban.grok.me/ 访问使用

看得见思考的编程智能体。

给它一个目标，它会自己拆步骤、调用工具、根据结果调整，直到把任务做完。不是一次答完的聊天框。

> 思考，然后动手。

---

## 它是什么

普通大模型：你问一句，它答一句，结束。

Circuit 是 Agent：你只给目标，它走 **ReAct** 循环——思考（Think）→ 行动（Act）→ 观察（Observe）——不断迭代，直到任务完成。每一步都摊开在界面上。

---

## 能做什么

- 用自然语言下达编程任务
- 自主规划步骤，逐步执行
- 调用工具真正动手：计算、写文件、跑代码、抓网页
- 产物写进虚拟工作区，可打开、修改、下载
- 左侧看轨迹，右侧看文件

### 内置示例

| 任务 | 它会做什么 |
| --- | --- |
| 计算并落盘 | 用计算器算 `(123 + 456) * 789`，写入 `result.txt` |
| 写函数并测试 | 写 `isPrime.js`，跑测试，结果写入 `primes.md` |
| 生成页面 | 写深色单页 `landing.html` |
| 抓取网页 | 抓取公开网页，整理成 `notes.md` |

## 构建流程

没有套现成 Agent 框架做演示，按三个零件从零搭。

```
用户给目标
        ↓
   ┌─────────┐     ┌─────────┐     ┌─────────┐
   │  思考    │  →  │  行动    │  →  │  观察    │
   │  Think  │     │   Act   │     │ Observe │
   └─────────┘     └─────────┘     └─────────┘
        ↑                               │
        └───────── 结果写回对话 ─────────┘
        直到最终答案，或达到 8 步上限
```

### 三块零件

| 零件 | 作用 | 实现 |
| --- | --- | --- |
| 大脑 | 推理、规划、决定调哪个工具、何时停 | xAI Grok（`grok-4.5`），Chat Completions + 原生 tool calling |
| 工具 | 真正动手：算、写、跑、抓 | 服务端执行，密钥不进浏览器 |
| 记忆 | 带着历史和工作区继续下一轮 | 对话消息 + 内存中的虚拟文件系统 |

### 主循环

1. 把任务、历史对话、当前工作区文件列表交给模型
2. 模型要么调用一个工具，要么给出最终答案
3. 若调工具：在服务端执行，把观察结果写回对话
4. 再问模型，进入下一轮
5. 最多 8 步，防止死循环

### 工具清单

| 工具 | 用途 |
| --- | --- |
| `calculator` | 精确计算，禁止心算 |
| `list_files` | 列出工作区文件 |
| `read_file` | 读取工作区文件 |
| `write_file` | 写入 / 覆盖工作区文件 |
| `run_js` | 在隔离沙箱执行 JavaScript |
| `web_fetch` | 抓取公开网页纯文本 |
| `get_time` | 取当前时间 |

## 怎么用

1. 点一个示例任务，或在底部输入框描述目标
2. 左侧看 ReAct 轨迹：思考、行动、观察
3. 右侧工作区查看 Agent 写出的文件
4. 需要停下就点停止；需要重来就点重置


---

## 设计原则

- **计算必须走计算器**，禁止心算，避免幻觉
- **代码必须在沙箱里真跑**，无 DOM、无网络、无 Node API
- **文件只存在于虚拟工作区**，不碰真实磁盘
- **每一步可见**，方便理解 Agent 在干什么
- **密钥只在服务端**，浏览器只负责展示
